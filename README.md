## vite project template for myself 

extends from [Vitesse](https://github.com/antfu/vitesse)

- Vue3 `<script setup>` Vite2

- typescript

- tailwind.css

- [ky](https://github.com/sindresorhus/ky)

- File based routing：[vite-plugin-pages](https://github.com/hannoeru/vite-plugin-pages)

- Components auto importing：[unplugin-vue-components](https://github.com/antfu/unplugin-vue-components)

- APIs auto importing：[unplugin-auto-import](https://github.com/antfu/unplugin-auto-import)

```bash
npx degit 459605823/v3-vite-template my-app
cd my-app
yarn
```
